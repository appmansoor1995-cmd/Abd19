# سجل الطلاب

برنامج لإدارة سجل الطلاب: الصف والشعبة والشهر، الغياب، المتابعة والدرجات، والملاحظات، مع نسخ احتياطي واستعادة بملف JSON.

## النشر على GitHub Pages
1. Settings ← Pages ← Source: Deploy from a branch ← main ← /(root).
2. الرابط: https://USERNAME.github.io/student-register/

## بناء ملف APK
من تبويب Actions ← Build APK ← Run workflow. عند الانتهاء نزّل الملف من Artifacts.
